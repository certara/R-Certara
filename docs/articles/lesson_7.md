In Lesson 7, we will demonstrate how to run simulations with RsNLME
models.

  
  
  

### Live Webinar Date: 10/26/2022 @10am EST

In the webinar we will cover the following topics:

- Define desired simulation output table with appropriate variables and
  time sequences
- Specify correct engine parameters for simulation
- Use the
  [`simmodel()`](https://certara.github.io/R-RsNLME/reference/simmodel.html)
  function to execute simulation
- Post-process simulation results and create diagnostic plots
