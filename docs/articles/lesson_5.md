In Lesson 5, we will continue to introduce the modeling capabilities of
the [`RsNLME`](https://certara.github.io/R-RsNLME/index.html) package
and demonstrate how to easily generate `ggplot2` based model diagnostics
plots using the
[`Certara.Xpose.NLME`](https://certara.github.io/R-Xpose-NLME/index.html)
and [`xpose`](https://uupharmacometrics.github.io/xpose/) packages.
Finally, we will explore additional plot customization options using
`ggplot2` commands.

  
  
  

### Webinar Overview

In the webinar we will cover the following topics:

- Creating a data object (`xpose_data`) in R from RsNLME model output
- Exploring model diagnostics with `xpose` and `Certara.Xpose.NLME` plot
  commands
- Extending and customizing model diagnostics with `ggplot2`
