Certara.R School Lesson 3 will demonstrate in depth applications of
Exploratory Data Analysis (EDA) in R using the
[`ggquickeda`](https://smouksassi.github.io/ggquickeda/) package.
Exploratory Data Analysis is a critical step in the pharmacometric
workflow, allowing you to understand your data and communicate
information effectively. The presenter of this lesson will be Dr.Samer
Mouksassi, who is the author of the
[`ggquickeda`](https://smouksassi.github.io/ggquickeda/) R package.

  
  

### Webinar Overview

In the webinar we will cover the following topics:

- Examine the value and scope of exploratory data analysis methods
- How to communicate information effectively using visual methods in R
- Demo Exploratory Data Analysis (EDA) with
  [`ggquickeda`](https://smouksassi.github.io/ggquickeda/)
