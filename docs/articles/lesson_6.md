In Lesson 6, we will explore model refinement. You will learn how to
create a new model with parameter estimates from a previously executed
model. We will then add covariates into our new model and explore their
impact using model diagnostic plots.

  
  
  

### Webinar Overview

In the webinar we will cover the following topics:

- Using the
  [`copyModel()`](https://certara.github.io/R-RsNLME/reference/copyModel.html)
  function to create a new model with parameter estimates from the
  fitted base model
- Adding covariates and fitting additional covariate models
- Exploring covariate effects using model diagnostic plots
