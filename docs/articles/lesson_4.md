In Lesson 4, we will introduce modeling capabilities with the
[`RsNLME`](https://certara.github.io/R-RsNLME/index.html) package and
show how we can leverage the [RsNLME Model
Builder](https://certara.github.io/R-RsNLME-model-builder/index.html)
Shiny GUI to create our models in R and learn the RsNLME model building
syntax, then extend our workflow to the R command line.

  
  
  

### Webinar Overview

In the webinar we will cover the following topics:

- Define base model
- Map columns to model variables
- Set initial estimates
- Fit model
