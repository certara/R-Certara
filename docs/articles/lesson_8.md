### Webinar Overview

In the webinar we will cover the following topics:

- Executing a VPC run in [`RsNLME`](https://certara.github.io/R-RsNLME/)
- Explore different binning and binless methods to compute VPC
  statistics in [`tidyvpc`](https://certara.github.io/tidyvpc/)
- Use the [`VPCResults`](https://certara.github.io/R-VPCResults/) Shiny
  App to parameterize a VPC from the GUI and generate corresponding R
  code for reproducibility in RStudio
- Customize the resulting VPC plot using
  [`ggplot2`](https://ggplot2.tidyverse.org/)
