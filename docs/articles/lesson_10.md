Lesson 10, we will provide a brief overview of RsNLME workflows that
we’ve covered in previous lessons, and demonstrate best practices for
organizing your project (e.g., directory structure, scripts, and run
output folders) to ensure reproducibility and traceability of your
results.

  

### Webinar Overview

In this webinar we will cover:

- Organizing Runs and Workflow
- Saving R Scripts and plot/table output to facilitate reporting
  objectives in Rmarkdown
- Using version control (GitHub Desktop) to track changes
- Sharing analysis with others to ensure reproducibility
