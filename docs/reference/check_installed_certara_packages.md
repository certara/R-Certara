# Check if Certara packages are installed

Check if Certara packages are installed

## Usage

``` r
check_installed_certara_packages(pkgs)
```

## Arguments

- pkgs:

  Character or character vector of package names. If missing, defaults
  to
  [`certara_packages()`](https://github.com/certara/R-Certara/reference/certara_packages.md)

## Value

Named logical vector indicating whether Certara package is installed

## Examples

``` r
if (FALSE) { # \dontrun{
check_installed_certara_packages()
} # }
```
