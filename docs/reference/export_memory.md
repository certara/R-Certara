# Export all per-user memory records to a JSON file

Export all per-user memory records to a JSON file

## Usage

``` r
export_memory(path)
```

## Arguments

- path:

  Destination file path.

## Value

Invisibly `path`.

## Examples

``` r
if (FALSE) { # \dontrun{
export_memory(tempfile(fileext = ".json"))
} # }
```
