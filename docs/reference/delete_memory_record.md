# Delete a single per-user memory record by id

Delete a single per-user memory record by id

## Usage

``` r
delete_memory_record(id)
```

## Arguments

- id:

  Record id.

## Value

Logical: whether a record was removed.

## Examples

``` r
if (FALSE) { # \dontrun{
delete_memory_record("mem-20260101120000-abcd")
} # }
```
