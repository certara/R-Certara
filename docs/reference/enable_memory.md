# Enable per-user memory

Enable per-user memory

## Usage

``` r
enable_memory(redact = NULL)
```

## Arguments

- redact:

  Optional character vector of regex patterns to scrub from stored free
  text (e.g. compound or project identifiers).

## Value

Invisibly the new config.

## Examples

``` r
if (FALSE) { # \dontrun{
enable_memory()
} # }
```
